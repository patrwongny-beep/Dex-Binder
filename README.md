# Dex Binder

Personal National Dex card tracker (Pokémon #1–1025), installable on Android as a web app.

- Open the GitHub Pages link in Chrome on Android, then menu → **Install app** (or **Add to Home screen**).
- Collection data and photos are stored only on the phone (IndexedDB). Use **Stats → Save backup file** regularly.
- Card search uses the Pokémon TCG API, falling back to TCGdex. Sprites come from PokeAPI.

`tools/` holds the source template and species list used to build `index.html`.
